USER GUIDE

Using MSX SpriteMate

Draw a sprite

  • Target selects the hardware the sprite data is for. MSX1 · TMS9918A uses the fixed 16-color palette and one color per sprite. MSX2 · V9938 Sprite Mode 2 allows a color per scanline and provides CC, IC, and EC controls. The target changes the available controls, preview, and generated output.
  • Choose an 8 × 8 or 16 × 16 sprite and select Single sprite or Sprite pair. The pair mode uses two independent sprites on MSX1 and supports Sprite 1's CC overlay on MSX2.
  • Click or drag on the canvas to draw. Right-click or hold Shift while drawing to erase.
  • In pair mode, edit both sprites separately. MSX2 can use Sprite 1 as a CC overlay. MSX1 uses independent colors and gives Sprite 0 priority wherever both sprites have a pixel. The inactive sprite appears translucently in its own color; while editing Sprite 1, a blue border marks its pixels underneath higher-priority Sprite 0 pixels.
  • MSX2 scanline settings include CC color mixing, IC conflict inhibit, and EC horizontal shift. MSX1 has one fixed-palette color per sprite, Early Clock, and 1× or 2× hardware magnification. Early Clock shifts the entire sprite 32 pixels left; hardware magnification doubles its size on the MSX1 screen.
  • Drag the preview's lower-right corner to resize it; the preview stays square. This changes only its on-screen size, is independent of hardware magnification, and does not change hardware output.

Choose colors

  • Color slots shows the active target's 16 sprite colors. MSX1 colors are fixed; MSX2 slots use a four-bit code and can be edited.
  • In MSX2 mode, click a slot to choose any of the 512 V9938 colors. Each RGB channel has 3 bits.
  • In Scanline settings, choose a palette slot for each sprite and line. Enable CC on Sprite 1 to apply overlap color mixing. IC inhibits sprite conflict detection; EC shifts that sprite 32 pixels left.
  • The CC color map shows the result for every pair of color codes.

Build an animation

  • Each row in Animations is a separate animation for this sprite. Rename a row by editing its name.
  • New animation starts a blank animation. Duplicate copies the whole animation, including frames, timing, and playback mode.
  • + Frame adds a blank frame. Duplicate frame copies the selected frame. Use the arrows to change frame order; Delete frame removes it.
  • Drag a frame onto another animation row to copy it there. Its frame duration is copied too; the original stays in place.
  • Select any frame to edit it, including while playback is running. Adding, removing, or moving frames does not stop playback.
  • Set the selected frame's duration with the slider. Turn on Same for all frames to apply that duration to every frame in the active animation; turn it off to set each frame separately. Then choose Loop or Ping-pong and press Play.

Save and export

  • Use Save project to download your editable project, or Open project to load one. A project stores its target, sprite size and mode, MSX1 magnification, sprites, animations, frame timing, and playback settings. The editor also remembers the selected target and magnification after a refresh.
  • Generated data updates as you edit. Choose C, Z80 Assembly, or MSX BASIC DATA in the format menu, then use the export button to download it.
  • Panels can be dragged by their headers and collapsed with the control in the panel heading.
ABOUT THIS EDITOR

MSX SpriteMate

MSX SpriteMate is an expanding sprite editor for the MSX family. It currently supports MSX1 TMS9918A and MSX2 V9938 Sprite Mode 2, with more targets and modes planned. It is based on Spritemate, the original Commodore 64 sprite editor.
